  偏差单位 μm（与配合卡同源；三联卡 mm 保持不动，图角标「偏差 μm」消歧）。
- **V4.7-02 布局冻结**（GB/T 1800.1 公差带图惯例：零线水平、上正下负、孔左轴右）：
  viewBox 220×104；值域线性映射 y∈[22,88]（跨 66），vMin/vMax 各夹 0（零线恒在
  框内）；零线 x∈[16,204]；带宽 36——孔 x[60,96]（中 78）、轴 x[124,160]（中
  142）、单带居中 x[92,128]（中 110）；s=66/(vMax−vMin)，y(v)=88−(v−vMin)·s。
- **V4.7-03 标签规则**：带码（H7/g6/h8…，轴小写沿 GB/T 口径）锚 middle 居带中、
  基线 = 带顶−3（字形被零线穿过则下压至零线下方 ≥2：g6 实测 63.88→65.8，
  字形顶 55.08 距零线 55 仅 0.08）；值标签锚点——孔带左侧 x=56（anchor end）、轴带/单带右侧
  x=132/164（anchor start）。值标签基线两档序（**零线穿字防御**，字形高度按
  0.8em=8.8、净空 2）：① 带外默认（上偏差 = 带顶−2.5、下偏差 = 带底+10）；
  ② 外置字形被零线穿过（字形与零线净空 <2）→ 收带内（上偏差 = 带顶+9.8、
  下偏差 = 带底−2.5，需带高 ≥12.5）。带高 <12.5 连带内也放不下 → 抛错保帧
  （居中方案在带高 3 合成案实测字形仍跨零线且与另一值标签同位，判不可画；
  真实 IT 数据带高 ≥15.7 不触发）。触发实例：g6 轴 es 带顶距零线 11.88<13.3、
  k6 轴 ei 带底距零线 5.28<12、H/h 单带 0 端 1.2<2。

## 2. 契约（types 归 core/tolerance-figure.ts 自持，不进 types.ts——页面私有视图）

```ts
export interface TolBandInput { code: string; kind: 'hole' | 'shaft' | 'single';
  lowerUM: number; upperUM: number }          // μm 带符号，lower ≤ upper
export interface TolBandRect { kind; code; x0: number; x1: number;
  yTop: number; yBot: number }                // 屏幕系 yTop < yBot
export interface TolLabel { text: string; x: number; y: number;
  anchor: 'start' | 'middle' | 'end'; role: 'code' | 'value' | 'unit' }
export interface TolFigureView { zeroLine: { x1: number; y: number; x2: number };
  bands: readonly TolBandRect[]; labels: readonly TolLabel[]; scale: number }
export function buildToleranceFigure(bands: readonly TolBandInput[]): TolFigureView
```
