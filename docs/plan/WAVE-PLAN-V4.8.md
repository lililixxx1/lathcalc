## 1. 裁决（编号登记）

- **V4.8-01 形值同源 + 行选择**：图由 `solveGearTrain` 真值驱动（V4.3-01 血统），
  画**当前选中行**（默认第 1 行 = 最优解）。结果表挂轮格 `a/b × c/d` 升级为

  重建结果表时选中态重置回第 1 行。同值齿数需两件注记保持不动。
- **V4.8-02 布局冻结**（教材复式挂轮展开画法，三轴共线水平布置）：
  viewBox 220×152；轴心线 cy=74；边距 10；**半径 = k·齿数**（统一模数比例，
  同副啮合真实外切），k = min(200/(2a+b+c+2d), 52/max(a,b,c,d))——宽度约束
  （左缘 O1−r_a=10 至右缘 O3+r_d≤210 的展开跨距）与高度约束（52 封顶，
  保上方标签 y≥cy−52−6=16 与下方 c 标签 y≤136 与轴注 y=147 不撞）取小。
  圆心：O1=10+r_a（主轴 a）；O2=O1+r_a+r_b（中间轴，b/c **同心**）；
  O3=O2+r_c+r_d（丝杠 d）。cap 约束时图不满幅（右缘 <210），如实呈现。
- **V4.8-03 标签与线型规则**（A4-R1 修订：b/c 清双缘）：齿轮标签 `a 20` 式
  （码小写 + 齿数）——a/d 贴各自圆缘（a 上侧 y=cy−r−6、d 下侧 y=cy+r+12，BOT_DY 10→12 系 A4-R2 修订：10 被字高 8.8 吃掉仅余 ~1.2 弧净空）；
  **b/c 同心双圆清双缘**（均避开较大圆弧：b 上 y=cy−max(r_b,r_c)−6、
  c 下 y=cy+max(r_b,r_c)+12——初版贴自身缘，实拍 b<c 时 c 顶弧穿 b 签
  1-2px@2x、b>c 时 b 底弧擦 c 签，R1 修订清 max）；**同行同侧碰撞守卫**：
  |Δy|<10 且 |Δx|<两签半宽和（0.58em·9.5px·字数）→ b 上推 11 / c 下推 11

  主轴/中间轴/丝杠（font 8）y=147 于 O1/O2/O3 正下。线型：三竖中心线
