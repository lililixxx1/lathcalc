## §1 契约变更（Lead 预置 commit，派工前）

`src/core/types.ts` `G76Params` 增可选字段：

```ts
/** 锥螺纹锥度位（W10-C）：起点与终点 X 轴半径差 mm；缺省/0 = 直螺纹（现状不变，向后兼容）。
 *  语义与各系统位名见 docs/research/g76-dialects.md §1：两行式/G92 = R（i 位）、HNC = I（起点相对终点半径差，常规锥螺纹为负）。

```

```ts

  throw new Error('PANIC: taper G76/G92 未实现（W10-C 待实现）');
}
```
