## 实现期计划修订（如实披露）

1. **V4.7-03 零线穿字防御为实测定稿**：计划初版仅规定带外基线（±2.5/+10），
   实现期自检发现两类工况零线穿字——g6 轴 es（带顶距零线 11.88，外置字形顶
   距线仅 1.68）、k6 轴 ei（带底距零线 5.28，外置字形整段被穿）；且 H/h 单带
   0 端外置字形距线仅 1.2。定稿为两档序（外置 → 收带内 topY+9.8/botY−2.5，
   带高 ≥12.5），带码同样防御（g6 码 63.88→65.8，字形顶距线 0.08→2.8）。
   计划 §1/§3 已同步。
2. **③ 居中兜底推翻为抛错**：计划初版第三档为「字形居零线与带边中点」，带高 3
   合成案实算字形 [79.1,86.7] 仍跨零线 82 且与另一值标签同位——判不可画，改为
   抛错保帧（真实 IT 数据带高 ≥15.7 不触发）。计划 §1/§3 已同步。
   （G2-V4.7 M1 勘正：居中字形 = 中点 83.5±4.4 = [79.1,86.7]，计划 §3 初笔
   77.9 误，已同步勘正。）
3. **角标位移**：初版「偏差 μm」(16,13) 顶部左上，与孔侧长值标签（+1550 级）
   保守盒相叠，且 CJK 实宽 > 0.58em 估值——改为「μm」(16,101.5) 左下。
4. 金锚勘正两处入档前修正：g6 孔 EI 带内基线按孔带底 55−2.5=52.5（初稿误写
   85.5）；g6/h7 下偏差外置 98 不入带内（初稿误标）。

- **机检**：`tools/verify-tol.mjs` 8 拍（默认 Ø40 H7 / Ø18 / IT8 / h / g6 / k6 /

  consoleErrors=0；每拍标签集逐字对拍、矩形数 1/2、零线 d 锚（88/22/55）、
  图变断言（d18/it8/h7/g6 对参考拍）、保帧断言（标签与矩形集逐位同 p6）。
- **视觉 R1（vision-reader，8 拍全量）**：**PASS（0 FAIL / 0 WARN / 8 PASS）**——
  逐张读出全部标签文字（含负号 U+2212、μm）；带数/相对位置/零线位置 8 张与
  预注册期望一致；无穿字/叠压/裁切。保帧拍确认图形与 p6 拍一致 + 橙色提示出现。
