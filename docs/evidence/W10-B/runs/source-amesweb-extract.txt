Key point: this table has NO "basic major diameter at gaging plane" column.
It publishes the gaging-plane PITCH diameter E1, from which the basic major
diameter at the gaging plane follows by the NPT basic profile relation
D = E1 + 0.8P (mechtool.cn prints this relation explicitly as "D2=d2=D-0.8P";
P1's table values satisfy it row-by-row).
The source-internal cross-check E0 - (basic minor at small end) = 0.8P holds
on the published rows, e.g. 5.39073 - 5.2907 = 0.10003 ~ 0.10000 and
6.44609 - 6.3461 = 0.09999 ~ 0.10000.
