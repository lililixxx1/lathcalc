## 说明

- >500 段两源共同覆盖 IT1–IT18（18 级）；GB/T 1800.3-1998 转写原表注「基本尺寸大于 500mm 的 IT1 至 IT5 的标准公差数值为试行」。
- 源 A 原表 IT12–IT18 以 mm 列出，本表已 ×1000 换算为 μm（如 0.7 mm → 700 μm）。
- 逐格原始输出：`runs/source-extraction.txt`（A/B 解析与对拍）、`runs/dual-source-verify.txt`（A/B/入库值三向）。
