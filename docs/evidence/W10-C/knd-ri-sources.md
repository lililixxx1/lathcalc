## 1. 源 A（A 级）：KND-1000T 车床用数控系统用户手册（B12B-T00N-0001，2006）

- 出处：`docs/research/g76-dialects.md` §2.1 来源 [8]（W6-C1 已存档逐字摘录）
- URL：`https://max.book118.com/html/2015/1001/26496342.shtm`
- 逐字摘录（§14.2.7 G76）：

  > 14.2.7 复合型螺纹切削循环(G76-切螺纹可以不需退刀槽)
  > `G76 P(m) (r) (a) Q(Δdmin) R(d) ;`
  > `G76 X(U) Z(W) R(i) P(k) Q(Δd) F(L) ;`
  > `Δdmin：最小切入量。…`
  > `d：精加工余量。…`
  > `I：螺纹部分的半径差 I=0为切削直螺纹。`
  > `K：螺纹牙高(X轴方向的距离用半径值指令)。`
  > `Δd：第一次切入量(同G32的螺纹切削)`
  > `注：用P、Q、R指定的数据，根据有无地址X(U)、Z(W)来区别。`
  > 示例：`G76 P011060 Q100 R200 ;`
  > `G76 X60640 Z25000 P3680 Q1800 F6.0 ;`

- 手册对 `R(i)` 的位义（起点/终点半径差）有定义，但**参数表与示例均未逐字标注 `R(i)` 单位**。
- 示例行的 `Q100 / R200 / P3680 / Q1800 / X60640 / Z25000` 只有按 0.001 mm 才与
  0.1 / 0.2 / 3.68 / 1.8 mm、60.640 / 25.000 mm 自洽；`g76-dialects.md` W6-C1 据此
  把 KND-1000T 的 `P/Q/R` 统一按 0.001 mm 处理。

## 2. 源 B（C 级，旁证）：用户问答两处

- URL 1：`https://zhidao.baidu.com/question/1707836333550397820`
- URL 2：`http://www.58che.com/wenda/1257443.html`
- 出处：`docs/research/g76-dialects.md` §2.1 来源 [9]/[10]
- 逐字摘录（两处高度一致）：

  > `G76 P020060 Q150 R0.03; G76 X Z-35.0 P Q R F ;`
  > `(第一行可以套用，Q是每次吃刀量，单位微米。R是精车余量，半径值)`
  > `(第二行:X、Z是目标点坐标，P是牙型高，Q是第一刀的吃刀量，R是...螺纹起点与终点的半径差，F是螺距...)`

- 该来源确认第二行 `R` 的**语义**为「螺纹起点与终点的半径差」，但**未给出 `R(i)` 数值示例或单位**；
  且第一行 `R0.03` 为 mm，与 KND-1000T 手册的 `R200`（0.001 mm）口径不一致，
  只能作语义旁证，不能作为 `R(i)` 单位依据。

## 4. 判定与代码落点

- 判定：**按 0.001 mm 口径推定**（唯一有 A 级示例自洽支撑的口径）。
- 代码：`src/core/gcode.ts` KND 分支 `R${Math.round(taper * 1000)}`；−9.6/32 = −0.3 → `R-300`。
- 口径注（p04 代码卡 `rc-codecard__comment`，KND + G76 + 锥管）：
  `按 KND-1000T 口径（P/Q/R=0.001mm）· R(i) 按 KND 全 P/Q/R 0.001mm 口径推定`。
- 回归：直螺纹 KND 行保持 v0.2 逐字符不变（R50 等）；KND G92 的 `R` 仍为 mm
  （G92 轴坐标示例 `X45. Z-100.` 为 mm 口径，且 V4 锚点冻结 `G92 … R-0.3`）。
