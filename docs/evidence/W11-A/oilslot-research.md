## 3. 判定

1. **结构形态**：检索到的唯一具体结构是 **G33 双螺旋**（`G33 X=R1+R2 Z-15 K20 SF=0`；`K20` = 导程 20 mm，`SF=0` = 起始角 0°；右旋/左旋两条螺旋槽 + 每次改变起始角度），不是 V4.1 §2 冻结的 `X = X₀ + A·SIN[360·Z/P]` 正弦摆动结构。
2. **多源一致性**：搜狐多篇、简书、ai.so.com 摘要的措辞与代码行完全一致（「大师傅都是这么玩的」+ 同一行 `G33 X=R1+R2 Z-15 K20 SF=0`），判为**同一篇文章的重复转载**；360 文库为另一条线索但只给标题/关键词，无完整宏代码。未找到第二条独立来源给出可逐位对照的完整 FANUC 宏结构 → **不满足「多源结构一致」**。
3. **出口选择**：按 V4.1 §2「检索不足 → 按上述自研结构实现，notes/口径注披露『自研近似结构，非标准工艺文件』」执行：
   - 实现结构：`X = X₀ + A·SIN[360·(Z−Zφ)/P]`，Z 按 ΔZ 逐点 G01；八字 = 两遍，第二遍 Zφ = P/2（相位差 180°）。
   - `src/core/macro.ts` 油槽 notes 第 4 条逐字含「自研近似结构，非标准工艺文件」。
4. **未采用检索结构的原因**：G33 双螺旋是另一种工艺机制（螺纹/螺旋槽插补），若改用它需要改 V4.1 冻结结构、重定锚点与参数域，超出 W11-A 写范围；已在最终报告「上报项」提请 Lead 裁决（保持自研正弦结构 / 另开卡按 G33 双螺旋实现）。
