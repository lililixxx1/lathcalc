# 车工算 LathCalc

开源免费、**完全离线**的中文车工计算器 PWA。为数控车工师傅做一个揣在兜里的算料工具：
查螺纹、出 G76、算切点、配公差、量重量——不联网、不注册、不要钱。

## 快速开始

```bash
npm install
npm run dev      # 开发
npm test         # 323 项测试（vitest）
npm run build    # 生产构建（PWA，dist/）
npm run preview  # 本地预览构建产物
```

构建产物为纯静态 PWA（Service Worker 预缓存全量资源）：部署到任意静态托管即离线可用，
**运行期零网络请求**。

## 技术栈

Vite + TypeScript + vitest，零框架（原生 TS + DOM），零运行时依赖。
三层架构：`src/core/`（计算内核，纯函数）→ `src/data/`（标准数据表 + 溯源）→ `src/ui/`（组件 + hash 路由 14 页）。

## 数据与精度说明

- 标准数据（螺纹四族/IT 公差/莫氏锥度/密度）录入自公开标准与双源互证，逐表溯源见
  [`src/data/PROVENANCE.md`](src/data/PROVENANCE.md)。
- 切削参数库为**示例数据**（非标准值），页面内固定警示「以试切为准」。
- G76 牙高 P 位取实际单边牙深 (d−d₁)/2（M30×3.5 → **P1894**），非工作牙高 H₁ 路径（1895）。
- 计算值与显示层双源：页面显示一律来自 core 输出，测试逐字符对拍（无显示层重算）。
