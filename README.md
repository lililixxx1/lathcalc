# 车工算 LathCalc

开源免费、**完全离线**的中文车工计算器 PWA。为数控车工师傅做一个揣在兜里的算料工具：
查螺纹、出 G76、算切点、配公差、量重量——不联网、不注册、不要钱。

## 快速开始

```bash
npm install
npm run dev      # 开发
npm test         # 544 项测试（vitest）
npm run lint     # eslint（0 error）
npm run build    # 生产构建（PWA，dist/）
npm run preview  # 本地预览构建产物
```

构建产物为纯静态 PWA（Service Worker 预缓存全量资源）：部署到任意静态托管即离线可用，
**运行期零网络请求**。

## 技术栈

Vite + TypeScript + vitest，零框架（原生 TS + DOM），零运行时依赖。
三层架构：`src/core/`（计算内核，纯函数）→ `src/data/`（标准数据表 + 溯源）→ `src/ui/`（组件 + hash 路由 16 页）。

## 数据与精度说明

- 标准数据（螺纹七族/IT 公差与基本偏差/莫氏锥度/密度/攻丝底孔）录入自公开标准与双源互证，逐表溯源见
  [`src/data/PROVENANCE.md`](src/data/PROVENANCE.md)；硬度换算表为 GB/T 1172 **单源披露**（转引无独立第二源，近似对照以原表为准）。
- 锥管口径：密封管 R（GB/T 7306）/锥管 NPT（GB/T 12716）的 d₂/d₁ 为**基准平面处直径**（1:16 锥），底孔=基面小径；NPT 收录 1/16–4（5/6 双源口径错位，第三源检索结案——无源以 141.300 为基面大径，宁缺毋滥不录）。
- G76/G92 方言语义按厂商手册 + 独立第二源双源取证冻结（来源分级见
  [`docs/research/g76-dialects.md`](docs/research/g76-dialects.md) §4.1）：KND 按 **KND-1000T** 口径
  （P/Q/R=0.001mm，其他机型单位可能不同）；GSK 按型号分口径——**988TA 为 mm 半径小数、980TDc 为 0.0001mm 增量
  （R 保持 mm）**，页面需先选型号；华中 G92 为工件坐标系设定（非螺纹循环），直进循环生成 **G82** 单循环行。
  **程序为参考模板，上机前请核对。**
- p03 → p04 程序生成覆盖六族（W10-C 起锥管 R/NPT 带 L 输入出锥度位）；蜗杆族仍不出 G76（非标准牙型，宁缺毋滥）。
- 切削参数库为**示例数据**（非标准值），页面内固定警示「以试切为准」。
- G76 牙高 P 位取实际单边牙深 (d−d₁)/2（M30×3.5 → **P1894**），非工作牙高 H₁ 路径（1895）。
- G92 输出为循环首行（单行），完整螺纹需后续 X 递减分刀。
- 计算值与显示层双源：页面显示一律来自 core 输出，测试逐字符对拍（无显示层重算）。
