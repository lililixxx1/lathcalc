## 4. 分歧值登记（唯一 1 格）

| 段 | 等级 | 主源值 | 分歧副源值 | 同值旁证 | 处置 |
| --- | --- | --- | --- | --- | --- |
| `(400,500]` | IT9 | **155 μm** | S7 MechBox = **160 μm** | S2 教材 155；S6 dooosp 155；S5 JoveWorks 155 | **已裁决采用 155（Lead 裁决 2，2026-11-03）** |

- 判定：孤值源 MechBox 判转抄错误；依据 = 等级公式复算 + 四源权重。
- 公式复算：标准公差因子 `i = 0.45·∛D + 0.001·D`，`D = √(400×500) = 447.21 mm` → `i = 3.888 μm`；`IT9 = 40i = 155.5 μm`，落在 155/156 舍入边界、明显远离 160（160 需 41.1i，无等级公式依据）。同段 `IT6=10i=38.9→40`、`IT7=16i=62.2→63`、`IT8=25i=97.2→97` 均与主源吻合，佐证该段 i 基准与舍入模式。
- 证据权重：主源 + 3 个独立副源（S2/S6/S5）= 155；160 仅 S7 单源孤值。
- 测试断言采用 155（`itToleranceMM(rows, 450, 9)=0.155` 作为数据层校验用例，非金测锚点）。

## 2. 换算口径（禁裸值）

- 螺距：`P = 25.4 / tpi`（mm）。JSON 存 IEEE-754 双精度**完整商值**，不预先舍入，
  避免换算误差累积；显示层再按位数排版。
  - 例：`25.4 / 20 = 1.27`；`25.4 / 13 = 1.9538461538461538`；
    `25.4 / 18 = 1.411111111111111`。
  - 测试以 `pitch === 25.4 / tpi`（严格相等，同一算式同一双精度结果）逐行校验。
- 大径：`major = 英寸分数 × 25.4`（mm）。
  - 例：`1/4 = 0.25 in × 25.4 = 6.35`；`5/16 = 0.3125 × 25.4 = 7.9375`；
    `9/16 = 0.5625 × 25.4 = 14.2875`；`1 in = 25.4`。
- designation 统一为 `尺寸-牙数 系列`（如 `1/4-20 UNC`、`1-8 UNC`），不带英寸引号；
  源表写作 `1/4"-20 UNC`、`1"-8 UNC`，引号差异属排版归一，不是数值分歧。

`src/core/arc.ts` 的 `judgeArcDirection` 及其文件头（第 26–44 行）冻结视图约定：

- G03：`图面逆时针＝前刀架 G03；X 上 Z 右、自 +Y 视；后刀架翻转`

FANUC 口径（G02 = CW，G03 = CCW，G18 ZX 平面）与该视图约定相容；差异只在「按哪个
观察方向数顺/逆」——arc.ts 固定为自 +Y 看，本表 desc 明示同一观察方向，避免图面歧义。

## 2. 半角算式

```
α/2 = atan( (D − d) / (2L) ) = atan( 1 / (2 × 锥度比值) )
```

DMS 串由 `src/core/arc.ts` 的 `degToDMS` 生成（度、分取整，秒四舍五入并处理进位）。
示例：MT4 `1:19.254` → `atan(1/(2×19.254)) = atan(1/38.508) = 1.487558565°` → `1°29′15″`。
