## 2. 半角算式

```
α/2 = atan( (D − d) / (2L) ) = atan( 1 / (2 × 锥度比值) )
```

DMS 串由 `src/core/arc.ts` 的 `degToDMS` 生成（度、分取整，秒四舍五入并处理进位）。
示例：MT4 `1:19.254` → `atan(1/(2×19.254)) = atan(1/38.508) = 1.487558565°` → `1°29′15″`。

## 4. 已知差异与说明

1. **MT4 halfAngleDMS**：按派工单算式得 `1°29′15″`；树内 Lead 迷你夹具
   `test/fixtures/morse.json` 记的是 `1°29′16″`。两者来自同一 `1:19.254` 的秒位舍入差
   （15.26″ 四舍五入 = 15″；16″ 应来自另一舍入口径或源表）。本表按派工单指定的
   `degToDMS(atan(1/(2r)))` 口径录 `1°29′15″`；夹具属 Lead 预置、按派工单禁改，未改动。
2. GB/T 1443-2016 原文未在线可读（见 §1 披露）；本表数值由 S2a/S2b 两份独立参考表核验，
   而非逐字抄自标准原文。若主会话要求“逐字对标准原文”，需采购/借阅标准纸质或付费电子版后复核。
