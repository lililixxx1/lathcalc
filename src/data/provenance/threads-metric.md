## 1. 来源（主源 / 副源）

- 官方记录：<https://openstd.samr.gov.cn/bzgk/gb/newGbInfo?hcno=2C17754B6D36AC9F46877E92221A3166>（检索日期 2026-11-03）

- 用途：粗牙/细牙螺距 P、大径系列、细牙优先序；表 1 脚注（① 仅用于发动机火花塞；② 仅用于轴承锁紧螺母；括号内螺距尽可能避免）。

### 主源 B：GB/T 196-2003《普通螺纹 基本尺寸》

- 标准号：GB/T 196-2003（2003-05-22 发布，2004-01-01 实施；官方状态：**废止**，被 GB/T 196-2025 代替）
- 官方记录：<https://openstd.samr.gov.cn/bzgk/gb/newGbInfo?hcno=963C4B41DC2889018A2AB5B5F82F373D>（检索日期 2026-11-03）
- 表值转载（权威转载）：<https://www.finesz.com/GB196.php>（GB/T 196-2003 基本尺寸表；检索日期 2026-11-03）
- 用途：大径 `D、d` = 公称直径；`D2/d2`、`D1/d1` 表值用于校核「大径 + 螺距」组合及公式输出（`d2=d−0.6495P`、`d1=d−1.0825P`）。
- **版本披露**：GB/T 196-2025（2025-03-28 发布，2025-10-01 实施；官方状态：现行）已代替 GB/T 196-2003。本卡按冻结计划与 `test/fixtures` 的 2003 版口径录入；官方全文系统因版权不提供在线阅读，本次未取得 2025 版全文表。已录值经副源 DIN 13 独立对拍，未发现差异；该版本问题列入交付报告「上报项」。

### 副源：DIN 13-1 / DIN 13-2…13-11（独立德标手册表）

- 粗牙：<https://www.gewinde-normen.de/en/iso-coarse-thread.html>（ISO Metric Coarse Thread DIN 13-1；检索日期 2026-11-03）
- 细牙：<https://www.gewinde-normen.de/en/iso-fine-thread.html> 及同目录 `iso-fine-thread-2.html` … `iso-fine-thread-10.html`（DIN 13-2…13-11；检索日期 2026-11-03）
- 性质：与 GB/T 193/196 不同出处的独立标准/手册表，非主源转载件。
- 用途：逐行核对每个 `(大径, 螺距)` 组合。DIN 13 细牙表含比 GB/T 193 更细的额外档（如 M2×0.2、M3×0.25、M25×0.35）；本表以 GB/T 193 表 1 为螺距系列权威，未录这些组合；对已录行两源值一致。

## 2. 逐行核对方法（可复跑）

对 `data/threads-metric.json` 的每一行执行三项检查：

1. **GB/T 193-2003 表 1**：大径 `D` 行、粗牙列或对应细牙 `P` 列命中，且 `P` 值相等；
2. **GB/T 196-2003 基本尺寸表**：同 `(D,P)` 行存在，大径 `D、d` = 公称直径；`d2/d1` 表值与
   `d−0.6495P` / `d−1.0825P` 的 3 位舍入一致（容差 0.0015 mm，覆盖表值舍入）；
3. **DIN 13-1（粗牙）或 DIN 13-2…13-11（细牙）**：同 `(D,P)` 组合存在。

核对结果：

| 检查 | 命中 | 说明 |
| --- | --- | --- |
| GB/T 193-2003 表 1 | 149 / 149 | 全部行的螺距-大径组合均来自表 1 |
| GB/T 196-2003 基本尺寸表 | 148 / 149 | M26×1 未列（见 §3），其余行的 d2/d1 表值与公式 3 位舍入一致 |
| DIN 13（独立副源） | 149 / 149 | 所有已录行均可在 DIN 13-1 或 DIN 13-2…13-11 查到 |
| **值冲突** | **0 行** | 两源对同一 `(D,P)` 的螺距值无相反记载 |

锚点独立复算（WAVE-PLAN §4 #7）：

- **M30 粗牙**：`d2 = d − 0.6495P = 30 − 0.6495×3.5 = 30 − 2.27325 = 27.72675` →
  表值/显示 **27.727**；GB/T 196-2003 基本尺寸表 M30 行 `d2=27.727`；DIN 13-1 `M30×3.5` 命中。
- `d1 = 30 − 1.0825×3.5 = 26.21125` → **26.211**；GB/T 196-2003 表值 `d1=26.211`。
- **M6→1.0、M10→1.5、M12→1.75、M20→2.5、M64→6.0**：GB/T 193-2003 表 1 粗牙列 +
  GB/T 196-2003 基本尺寸表 + DIN 13-1 三方一致。

## 4. 细牙选取口径

- 每大径按 **GB/T 193-2003 表 1 细牙列优先序**（8→6→4→3→2→1.5→1.25→1→0.75→0.5→0.35→0.25→0.2）
  取前 3 档；
- 排除：`-`（无此组合）、括号内（尽量避免）、与粗牙同值（去重）、注①/②（限定用途）；
- 粗牙 39 档：M1–M64 粗牙列全部非 `-` 行（含第 2/3 系列直径，如 `M1.1`、`M9`、`M11`、`M39`）；
  `M5.5 / M15 / M17 / M25 / M26 / M28 / M32 / M35 / M38 / M40 / M50 / M55 / M58 / M62`
  为第 3 系列细牙专用大径，无粗牙行。

## 5. 数据模型说明

- `ThreadRow`（`src/core/types.ts`）仅承载 `family / designation / pitch / major / coarse? / tpi? / source`；
- `major` = GB/T 196-2003 基本尺寸表的大径 `D、d` = 公称直径；
- `d2 / d1 / H1 / 底孔 / 最佳针径` 由 `src/core/thread.ts` 按 WAVE-PLAN §4 冻结常数集计算，不落入 JSON；
- `tpi` 不适用于 metric；细牙行按派工单省略 `coarse`；粗牙行 `coarse=true`。
