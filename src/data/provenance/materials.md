## 3. 使用边界

1. **不是标准值**：本表不是 GB/T、刀具商样本或任何权威切削数据库的逐条转写；量级仅供 UI 示例/占位。
2. **必须试切**：实际 Vc/f 受材料状态（硬度/热处理）、刀具材质与涂层、机床刚性、装夹、冷却影响，须从区间下沿试切并逐步修正。
3. **UI 义务**：材料页须展示固定警示“示例数据，试切为准”，并在结果卡标注来源性质（WAVE-PLAN §3 裁决 3）。
4. 若后续要转为“可推荐参数库”，须按 B.2 双源规则补每行两源 + URL + 检索日期，并过 G2 复核；本卡不做该升级。
